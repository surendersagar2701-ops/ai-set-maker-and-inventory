# 🏪 Bangle Store AI

Smart Inventory & AI Set Maker for Bangle Store

## Features
- ✨ AI Colour Detection (Google Vision API)
- 📷 QR/SKU Scanner
- 📚 Bulk Import
- 🧾 Billing System
- 📊 Reports
- 📝 Daily Parcha
- 📱 PWA Installable

## Setup
1. Get Google Vision API Key from Google Cloud Console
2. Add API key to config.js
3. Deploy on GitHub Pages

## Technologies
- HTML, CSS, JavaScript
- Google Vision API
- Tesseract.js OCR
- html5-qrcode
- PWA
